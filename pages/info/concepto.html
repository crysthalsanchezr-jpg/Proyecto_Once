CONOCE EL CONCEPTO

¿Qué es el Bullying?

Comprender el bullying es el primer paso para reconocerlo, prevenirlo y construir espacios donde todas las personas puedan sentirse seguras.

DEFINICIÓN

Una forma de violencia que no debe normalizarse

El bullying es una conducta de agresión intencional y repetida que puede presentarse entre estudiantes y que busca causar daño, intimidación, humillación o exclusión.

Puede manifestarse de diferentes maneras y afectar el bienestar, la convivencia y la participación de quienes lo experimentan.

01

¿Cómo reconocerlo?

Algunas características permiten diferenciar el bullying de un conflicto ocasional.

Repetición

Las conductas agresivas pueden repetirse a lo largo del tiempo y generar una situación persistente.

Intencionalidad

Existe una intención de causar daño, intimidar, humillar o afectar a otra persona.

Desequilibrio

Puede existir una diferencia de poder, influencia o capacidad para defenderse.

02

Formas en que puede manifestarse

El bullying puede adoptar diferentes formas.

Físico

Conductas que buscan afectar físicamente a otra persona.

Verbal

Insultos, burlas, amenazas o expresiones destinadas a humillar.

Social

Exclusión, aislamiento o acciones destinadas a afectar las relaciones sociales.

Ciberbullying

Conductas de acoso realizadas mediante redes sociales, mensajes u otros medios digitales.

PARA RECORDAR

El silencio no soluciona el problema.

Reconocer una situación de bullying, buscar apoyo y promover el respeto son acciones importantes para construir una convivencia saludable.
